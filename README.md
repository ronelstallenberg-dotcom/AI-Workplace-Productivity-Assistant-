# AI productivity hub

Build a single integrated, responsive AI-Powered Workplace Productivity Assistant dashboard with sidebar navigation, modern professional SaaS design, white background and purple, light blue and pink accents.

Include these 3 AI tools:

Smart Email Generator – generate professional emails in Formal, Friendly and Persuasive tones.

AI Research Assistant – summarise topics and articles, provide detailed insights and recommendations.

AI Chatbot – interactive workplace assistant that answers user prompts.

Each tool must have user input fields, a visible structured AI prompt, detailed topic-specific outputs, editable responses, Copy and Regenerate buttons.

Include a dashboard, input/output sections, responsive desktop/mobile layout and Responsible AI disclaimer.

Frontend only, no backend or API. Use realistic interactive demo responses. Ensure a polished, user-friendly and fully integrated application.
